# 指名ルーレット

授業でランダムに生徒を指名するためのルーレットアプリです。ブラウザだけで動きます。

**👉 [https://edu-tools-jp.github.io/roulette/](https://edu-tools-jp.github.io/roulette/)**

インストールも会員登録も不要です。上のリンクを開けばすぐ使えます。

---

## できること

- **クラスごとに名簿を管理**できます。1組・2組…と作っておけば、授業のたびに切り替えるだけです。
- **Excelから名簿を取り込めます。** ファイルを選ぶと、姓・名の列を自動で推測して取り込み前に一覧で確認できます。手入力やコピー＆ペーストにも対応しています。
- **名前の表示は「フルネーム／姓のみ／名のみ」から選べます。** 40人クラスでも「姓のみ」なら盤面がはっきり読めます。
- **特定の生徒を抽選対象から外せます。**（下記参照）
- **一度当たった人を除外**するかどうかを、その場で切り替えられます。全員に1回ずつ当てたいときと、何度でも当たってよいときで使い分けられます。
- **投影モード**にすると設定や履歴が隠れ、盤面と結果だけが大きく表示されます。プロジェクターでの投影用です。

## 抽選対象から外す設定について

場面緘黙など、指名すること自体が負担になる生徒への配慮のための機能です。

名簿画面で「対象外」にチェックを入れると、**その生徒は盤面にはほかの生徒と同じように並びますが、当たることはありません。**

盤面上の色や文字に違いは付けていないため、**誰が対象外に設定されているかは画面からは分かりません。** 設定を確認・変更できるのは名簿画面だけです。

### 一点ご注意

「一度当たった人を除外する」をオンにしたまま全員に当て終えると、盤面に残るのは対象外の生徒だけになります。1周し終えたら「リセット」を押してください。

## 使い方

1. 「名簿」タブを開きます。
2. 「Excelから取り込む」または「直接入力・貼り付け」で名前を登録します。
   - Excelの2列（姓・名）を選んでコピーし、そのまま貼り付けることもできます。
   - 「山田 太郎」のように1つのセルにフルネームが入っている場合は、自動で姓と名に分けます。
   - 姓だけ、名だけの名簿でもそのまま使えます。
3. 配慮が必要な生徒がいれば「対象外」にチェックを入れます。
4. 「ルーレット」タブに戻り、「スタート」を押します。（キーボードのスペースキーでも回せます）

クラスを増やすときは、名簿画面の左側「クラス」の「＋ 追加」から作成します。

## アプリとして入れる

Chrome / Edge のアドレスバー右の「インストール」アイコンから、デスクトップアプリのように入れられます（任意）。

- 一度開けば、**ネットにつながっていなくても起動**します。
- 新しい版が出ると、画面上の **「更新」ボタンが緑色に光ります**。押すと更新内容が表示され、読んでから更新するか決められます。
- 「更新」を押さなくても、アプリを全部閉じて開き直せば新しい版になります。
- 更新すると画面が再読み込みされ、その時間の指名の記録（履歴）はリセットされます。名簿と設定はそのまま残ります。

## データの保存について

**入力した名簿は、使っているブラウザの中だけに保存されます。** サーバーには一切送信されません。名前は個人情報なので、外部に出ない作りにしています。

そのため、次の点にご注意ください。

- 別のパソコンやブラウザでは、名簿は引き継がれません。
- ブラウザの「閲覧履歴データの削除」でサイトデータを消すと、名簿も消えます。
- シークレットウィンドウでは、閉じた時点で消えます。

学年の始めに一度名簿を作っておき、同じパソコンの同じブラウザで使うのがおすすめです。

## 動作環境

Google Chrome（最新版）で動作を確認しています。Edge、Safari、Firefox でも動きます。
スマートフォンやタブレットの画面幅にも対応しています。

## ローカルで動かす

そのまま開くだけでも動きますが、簡易サーバー経由での起動をおすすめします。

```bash
git clone https://github.com/edu-tools-jp/roulette.git
cd roulette
python3 -m http.server 8765
```

ブラウザで `http://localhost:8765` を開きます。ビルドは不要です。

## 構成

```
index.html               画面
assets/styles.css        スタイル
assets/app.js            ロジック（ルーレットの描画・抽選・名簿管理・Excel取り込み・更新確認）
service-worker.js        オフライン動作と更新の管理
manifest.webmanifest     アプリとして入れるときの名前・アイコンの定義
release-notes.json       更新内容（「更新」ボタンを押したときに表示）
icon-192.png / icon-512.png / icon-maskable.png / apple-touch-icon.png / favicon-32.png
                         アイコン（元データは icons/ の SVG）
vendor/xlsx.full.min.js  SheetJS（Excel読み込み用・同梱）
```

外部CDNに依存しないよう、SheetJS はリポジトリに同梱しています。校内のネットワークが不安定でも Excel の取り込みが動きます。

## 新しい版を公開するとき

PDFノートと同じ手順です。

1. ファイルを直して GitHub に上げます。
2. **版番号を2か所、同じ値に書き換えます。** 片方だけだと「表示中のファイルが古いようです」という案内が出ます。

   ```js
   // service-worker.js
   const VERSION = '20260916b';       // ← これを新しい値に変える

   // assets/app.js
   const APP_VERSION = '20260916b';   // ← 上とまったく同じ値にする
   ```

   書式は「更新日＋枝番」＝ `20260916a`（同じ日に2回目なら `20260916b`）。
   `service-worker.js` の VERSION が変わらないと、ブラウザは「更新なし」と判断して新しい版を取りに行きません。

3. **`release-notes.json` のいちばん上に、今回の版の項目を足します。**

   ```json
   [
     {
       "version": "20260917a",
       "title": "何が変わったかの見出し",
       "items": ["先生に伝えたいことを1行ずつ", "…"]
     },
     ← これまでの分はこの下にそのまま残す
   ]
   ```

   `version` は上の版番号と同じ値にします。使っている版より新しい項目だけが、「更新」を押したときの確認画面に出ます。

4. 1〜2分で GitHub Pages に反映され、使っている側では起動時（と1時間ごと）の確認で「更新」ボタンが緑色になります。

### アイコンを変えるとき

アイコンの画像を差し替えたうえで、上と同じように版番号を上げてください。アプリの中の画像は「更新」で新しくなります。

デスクトップやタスクバーに出るアイコンは、Chrome が自分の間隔で確認して切り替えます。すぐには変わらないことや、Chrome から確認の表示が出ることがあります。Windows が古いアイコンを覚えている場合は、アプリを入れ直すと新しいアイコンになります。
