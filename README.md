# 指名ルーレット

授業でランダムに生徒を指名するためのルーレットアプリです。ブラウザだけで動きます。

**👉 [https://edu-tools-jp.github.io/roulette/](https://edu-tools-jp.github.io/roulette/)**

インストールも会員登録も不要です。上のリンクを開けばすぐ使えます。

---

## できること

- **クラスごとに名簿を管理**できます。1組・2組…と作っておけば、授業のたびに切り替えるだけです。
- **Excelから名簿を取り込めます。** ファイルを選ぶと、姓・名の列を自動で推測して取り込み前に一覧で確認できます。手入力やコピー＆ペーストにも対応しています。
- **名前の表示は「フルネーム／姓のみ／名のみ」から選べます。** 40人クラスでも「姓のみ」なら盤面がはっきり読めます。
- **特定の生徒を抽選対象から外せます。**（下記参照）
- **一度当たった人を除外**するかどうかを、その場で切り替えられます。全員に1回ずつ当てたいときと、何度でも当たってよいときで使い分けられます。
- **投影モード**にすると設定や履歴が隠れ、盤面と結果だけが大きく表示されます。プロジェクターでの投影用です。

## 抽選対象から外す設定について

場面緘黙など、指名すること自体が負担になる生徒への配慮のための機能です。

名簿画面で「対象外」にチェックを入れると、**その生徒はルーレットの盤面にも表示されません。** 名前が盤面に出たまま当たらない状態だと、本人にも周囲にも気づかれてしまうため、盤面から完全に外す作りにしています。

名簿の一覧には残るので、出席番号や人数の確認には引き続き使えます。

## 使い方

1. 「名簿」タブを開きます。
2. 「Excelから取り込む」または「直接入力・貼り付け」で名前を登録します。
   - Excelの2列（姓・名）を選んでコピーし、そのまま貼り付けることもできます。
   - 「山田 太郎」のように1つのセルにフルネームが入っている場合は、自動で姓と名に分けます。
   - 姓だけ、名だけの名簿でもそのまま使えます。
3. 配慮が必要な生徒がいれば「対象外」にチェックを入れます。
4. 「ルーレット」タブに戻り、「スタート」を押します。（キーボードのスペースキーでも回せます）

クラスを増やすときは、名簿画面の左側「クラス」の「＋ 追加」から作成します。

## データの保存について

**入力した名簿は、使っているブラウザの中だけに保存されます。** サーバーには一切送信されません。名前は個人情報なので、外部に出ない作りにしています。

そのため、次の点にご注意ください。

- 別のパソコンやブラウザでは、名簿は引き継がれません。
- ブラウザの「閲覧履歴データの削除」でサイトデータを消すと、名簿も消えます。
- シークレットウィンドウでは、閉じた時点で消えます。

学年の始めに一度名簿を作っておき、同じパソコンの同じブラウザで使うのがおすすめです。

## 動作環境

Google Chrome（最新版）で動作を確認しています。Edge、Safari、Firefox でも動きます。
スマートフォンやタブレットの画面幅にも対応しています。

## ローカルで動かす

そのまま開くだけでも動きますが、簡易サーバー経由での起動をおすすめします。

```bash
git clone https://github.com/edu-tools-jp/roulette.git
cd roulette
python3 -m http.server 8765
```

ブラウザで `http://localhost:8765` を開きます。ビルドは不要です。

## 構成

```
index.html          画面
assets/styles.css   スタイル
assets/app.js       ロジック（ルーレットの描画・抽選・名簿管理・Excel取り込み）
vendor/xlsx.full.min.js  SheetJS（Excel読み込み用・同梱）
```

外部CDNに依存しないよう、SheetJS はリポジトリに同梱しています。校内のネットワークが不安定でも Excel の取り込みが動きます。
